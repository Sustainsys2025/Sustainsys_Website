Environment Setup

Configure Your Development Environment

Get started with the Intelliquest Agentic Framework by leveraging agent APIs

Prerequisites
  • Intelliquest Framework access (contact admin)
  • Environment selection: Dev, INT, or Prod
  • Client ID — unique identifier for your client
  • Project ID — your project's unique identifier
  • Workspace ID — your team's workspace
  • App Key — authentication key for API access
  • Python 3.9 or higher installed
  • Postman (latest version)
Environment Configuration
  • Install Postman from postman.com/downloads
  • Import the Intelliquest collection
  • Create environment variables: client_id, project_id, workspace_id
  • Configure pre-request scripts for auto-injection
  • Set base URLs for State API and Event API
  • Test connection with health check endpoint
  • Verify all headers are properly configured
Token Generation
  • Call LoginAPI with app_key and redirect_url
  • Copy generated URL and open in browser
  • Complete authentication steps
  • Extract token from browser cookies
  • Paste token into Postman's auth_token variable
  • Tokens expire — regenerate as needed
Required Headers
  • x-client-id: {{client_id}}
  • x-project-id: {{project_id}}
  • x-workspace-id: {{workspace_id}}
  • Authorization: Bearer {{auth_token}}
  • Content-Type: application/json
  • Accept: application/json
curl --location 'https://api.intelliquest.sustainsys.co.uk/v2/auth/login?redirect_url=...' \
  --header 'accept: application/json' \
  --header 'app-key: YOUR_APP_KEY'
03 — Build Your First Agent

Create, Configure & Deploy

Build intelligent agents using the Intelliquest Agentic Framework

Agent Creation

Use the Agent API to create an agent with:

  • System Prompts — define persona & capabilities
  • Input Schema — JSON format specification
  • Output Schema — response structure
  • Model Configuration — LLM provider & params
  • Behavioral Guidelines — agent constraints

Tools Configuration

Supported tool types:

  • API Tool — external REST APIs
  • Script Tool — Python scripts in isolation
  • MCP Tool — Model Context Protocol
  • MCP-Runtime Tool — dynamic loading
  • Custom Tools — extend as needed

Tasks Configuration

Define tasks with:

  • Task Name — clear identifier
  • Description — detailed explanation
  • Input/Output Specs — data formats
  • Mapping — auto-assigned by reasoning
  • Dependencies — task ordering
// Example Input Schema
{
  "type": "object",
  "properties": {
    "repo_url": {"type": "string", "description": "Git repository URL"},
    "branch": {"type": "string", "default": "main"}
  },
  "required": ["repo_url"]
}

06 — Support

Troubleshooting & Resources

Resolve issues quickly with expert guidance

🔧 Troubleshooting Tips

Token Expired: Regenerate via LoginAPI, update Postman variable
Incorrect Headers: Verify pre-request script and environment variables
Tool Input Errors: Validate input against schema, check required fields
Execution Timeout: Increase timeout, check tool performance
Rate Limited: Implement backoff strategy, request quota increase
