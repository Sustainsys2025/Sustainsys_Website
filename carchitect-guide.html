Section 1 of 10

Platform Overview

CARchitect is a web-based platform developed by Sustainsys that enables researchers to design next-generation chimeric antigen receptor (CAR) constructs for cell and gene therapy. The platform combines a curated database of validated CAR components with AI-powered analysis to accelerate the design process from weeks to minutes.

The system runs entirely on local infrastructure — no cloud API keys, no data leaving your network. A biomedical language model (BioMistral 7B) runs on your hardware via Ollama, providing domain-specific AI capabilities without external dependencies.

What CARchitect Does

🧬 CAR Design

AI-guided full construct design. Specify a target antigen, cell type, and generation — CARchitect recommends optimal components with scientific justification from clinical trial data.

🔬 Sequence Analysis

Analyse amino acid sequences for domain boundaries, immunogenic epitopes, post-translational modification sites, and hydrophobicity profiles.

⚙️ Construct Optimisation

Evaluate existing constructs for expression efficiency, protein folding stability, signaling potency, and manufacturing considerations.

📚 Component Library

Browse 50+ validated components sourced from FDA-approved therapies including Kymriah, Yescarta, Tecartus, Breyanzi, and Abecma.

🧪 scFv Analysis

CDR identification, framework assessment, VH/VL interface stability prediction, aggregation hotspot detection, and humanisation scoring.

📦 Export & Share

Export designs in FASTA, GenBank, or JSON formats. Generate construct summaries for lab notebooks and regulatory submissions.

Request Flow

1

User Authenticates

User visits /demo/login, enters credentials. Flask validates against the demo user database and creates a secure session cookie.

2

Frontend Sends AI Request

User configures a CAR design (target antigen, cell type, generation) and clicks "Generate". JavaScript POSTs to /api/generate with the feature name and prompt.

3

Backend Selects System Prompt

Flask maps the feature name (e.g., "car_designer") to a domain-specific system prompt that instructs the LLM on its role, expected output format, and scientific rigour requirements.

4

Ollama Generates Response

The combined system + user prompt is sent to BioMistral via Ollama's API. Temperature is set to 0.3 for focused, factual responses. Typical inference: 30–60 seconds on 16GB RAM.

5

Result Returned to Browser

Flask returns the AI response as JSON. The React frontend renders it in a styled result box with loading states and error handling.

CAR Biology Primer

A Chimeric Antigen Receptor (CAR) is a synthetic receptor engineered to redirect immune cells (T cells or NK cells) to recognise and kill cancer cells. CARs combine an extracellular antigen-binding domain with intracellular signaling domains, creating a modular protein that can be customised for different targets and therapeutic profiles.

CAR Generations

1st

First Generation

scFv + CD3ζ only. Provided activation but poor persistence and expansion in vivo.

2nd

Second Generation

Added one costimulatory domain (CD28 or 4-1BB). Used in all current FDA-approved products.

3rd

Third Generation

Two costimulatory domains (e.g., CD28 + 4-1BB). Enhanced signaling but increased vector size.

4th

Fourth Generation

"Armoured" CARs with cytokine payloads, safety switches (iCasp9), or immune checkpoint modulators.

CARchitect supports all four generations and both CAR-T and CAR-NK cell types. The platform's component library sources data from six FDA-approved CAR therapies: Kymriah (tisagenlecleucel), Yescarta (axicabtagene ciloleucel), Tecartus (brexucabtagene autoleucel), Breyanzi (lisocabtagene maraleucel), Abecma (idecabtagene vicleucel), and Carvykti (ciltacabtagene autoleucel).

Section 5 of 10

AI Engine & System Prompts

The AI engine uses a role-based prompt architecture. Each CARchitect feature (design, analysis, optimisation) has a dedicated system prompt that defines the LLM's expertise, expected output format, and scientific standards. This ensures consistent, domain-appropriate responses.

Six Specialised AI Roles

car_designer

Full CAR construct design expert. Recommends components with clinical trial citations, considers immunogenicity and cell type compatibility.

component_generator

Novel component design. Provides amino acid sequences, binding predictions, immunogenicity assessment, and validation suggestions.

construct_optimizer

Optimisation specialist. Evaluates expression efficiency, protein folding, signaling potency, safety, and manufacturing feasibility.

sequence_analysis

Bioinformatics expert. Predicts secondary structure, immunogenic epitopes, PTM sites, hydrophobicity profiles, and sequence homology.

scfv_analysis

Antibody engineering specialist. CDR identification, framework assessment, VH/VL stability, aggregation hotspots, humanisation scoring.

full_car_analysis

Comprehensive construct analyst. Maps all domains from signal peptide to CD3ζ, assesses each for functionality and optimisation opportunities.

Prompt Engineering Pattern

Each request to Ollama follows this structure:

PROMPT TEMPLATE
System Prompt
<s>[INST] {system_prompt}
User Request
User request: {user_prompt} [/INST]

Temperature = 0.3 — We use a low temperature for focused, factual responses. In biomedical contexts, creativity is less important than accuracy. The model cites real proteins, published sequences, and clinical trial identifiers rather than inventing plausible-sounding but fictional data.

Authentication & Security

The demo instance uses Flask session-based authentication. Users must log in at /demo/login before accessing the application. Sessions are managed via secure cookies with a server-side secret key. The server blocks direct access to all HTML pages and only serves the app through the authenticated /demo/app route.

Deployment & Cloudflare Tunnel

The production deployment uses three processes running on a Mac Mini: Ollama (model inference), Flask (web server), and cloudflared (secure tunnel). Cloudflare Tunnel eliminates the need for port forwarding, static IP, or SSL certificate management.

Deployment Steps

1

Install Dependencies

pip install flask flask-cors requests — three Python packages. Ollama from ollama.com. cloudflared via brew install cloudflared.

2

Pull the AI Model

ollama pull cniongolo/biomistral — one-time 4.4GB download. Model weights are cached locally.

3

Create Cloudflare Tunnel

cloudflared tunnel create carchitect-demo — creates a named tunnel. Then cloudflared tunnel route dns to create a CNAME record pointing your subdomain to the tunnel.

4

Start All Services

Three terminal tabs: Ollama (auto-starts), python3 server.py, and cloudflared tunnel run. The site is live at your custom domain with full HTTPS.

Roadmap & Vision

CARchitect is actively being developed. The current demo showcases the core platform capabilities. Here is the planned feature roadmap for future releases.

Sequence Database Integration

Connect to NCBI, UniProt, and IMGT databases for real-time sequence retrieval and cross-referencing against published CAR constructs.

3D Structure Prediction

Integrate AlphaFold or ESMFold for scFv structure prediction. Visualise antigen-binding interfaces and assess structural stability.

Immunogenicity Scoring

Computational T-cell epitope prediction using NetMHCpan. Flag high-risk sequences before experimental validation.

Multi-User Collaboration

Team workspaces with saved designs, version history, and role-based access. Supabase authentication for production deployment.

Vector Design Assistant

Extend from protein to DNA level — codon optimisation, restriction site avoidance, and lentiviral vector packaging size constraints.

Clinical Trial Mapping

Map designed constructs to similar CARs in active clinical trials. Cross-reference ClinicalTrials.gov for safety and efficacy signals.
