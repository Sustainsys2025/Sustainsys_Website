"Show me in Python how gradient descent finds the minimum."
# Your tutor generated this — tap to run def gradient_descent(start, lr=0.1, steps=20): x = start for _ in range(steps): grad = 2 * x # d/dx of x² x = x - lr * grad return x print(gradient_descent(8.0)) # ≈ 0.09
Each step, we move opposite to the gradient — like rolling downhill. The learning rate lr controls how big the step is.
